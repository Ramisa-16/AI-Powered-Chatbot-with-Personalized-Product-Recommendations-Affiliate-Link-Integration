<p align="center">An intelligent chatbot that recommends personalised products based on user preferences and embeds affiliate links — combining conversational AI with monetised e-commerce recommendations.</p>

---
## ✨ Features
- Conversational product discovery
- Personalised recommendations based on chat context
- Automatic affiliate link embedding
- Commission tracking per recommendation
- Multi-platform integration (website, WhatsApp, Telegram)

## 🏗️ Pipeline
```
User Chat → Intent Detection → Preference Profiling
→ Product Matching → Affiliate Link Generation → Response
```

## 🚀 Getting Started
```bash
git clone https://github.com/Ramisa-16/AI-Powered-Chatbot-with-Personalized-Product-Recommendations-Affiliate-Link-Integration.git
pip install -r requirements.txt && python main.py
```
